## Introduction
This dataset contains stated choice data and personal characteristics including sociodemgraphic characteristics and mobility characteristics of the respondents. This data has been collected from an online survey.

## Data
A stated choice experiment was conducted to understand the willingness to become an occasional carrier and possibility of newly generated trips in crowdshipping services. In addition, personal characteristics such as sociodemographic characteristics, mobility and attitudinal charcterisrtics of the respondents are collected to explore how these variables influence the choice becoming an occasional carrier in crowdshipping services. 

## Description of the data set
The choice data file (database_final.csv) contains data from the experiment and relevant personal characteristics.
